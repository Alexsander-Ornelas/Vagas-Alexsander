# Vagas-Alexsander

Site da automação de busca de vagas do Alexsander Ornelas (Analista de Dados · Engenheiro de Dados · BI).

- **Início:** resumo das vagas e candidaturas
- **Vagas:** vagas encontradas, cada uma com currículo ajustado para download
- **Status:** andamento das candidaturas nas plataformas

Publicado com GitHub Pages: https://alexsander-ornelas.github.io/Vagas-Alexsander/
